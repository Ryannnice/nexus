## 🧭 技术方向

团队长期关注四个技术方向：

| 方向 | 关注内容 |
|---|---|
| **LLM（后训练）算法** | 监督微调、偏好优化、强化学习、数据构建与评测 |
| **Agent** | 工具使用、任务规划、记忆、检索与多智能体协作 |
| **具身智能** | 视觉-语言-动作模型、机器人学习、感知、规划与控制 |
| **推荐系统** | 召回、排序、用户建模、多目标优化与工业实践 |

## 🛠️ 本仓库 / 网站

纯静态站点，零构建依赖，通过 **GitHub Pages** 托管。

```
nexus/
├── index.html   # 单页主站
├── style.css    # 设计系统（NVIDIA 风格 · 黑白灰 + #76b900）
├── script.js    # 导航 / 滚动交互
└── README.md
```

**本地预览**：直接用浏览器打开 `index.html` 即可，或

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

**贡献学习资料**：欢迎提 Issue 或 PR，在对应分类的卡片网格中追加条目即可。
