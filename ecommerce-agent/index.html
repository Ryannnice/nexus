PROJECT ABSTRACT

项目摘要

本项目围绕同一份 100 工具 Catalog 连续完成三阶段实验：作业 1 构建数据并训练 Intent Gate；作业 2 以 BM25、任务内微调 Embedding、Task Reranker 和 RRF 返回高覆盖 Top-K；作业 3 在完整目录或 RAG@10 候选上生成有序工具 ID 轨迹。

LATEST PROGRESS · ASSIGNMENT 3 SetEM / TraceEM · 99.00%

Qwen3-4B SFT + RAG@10 在独立冻结 API 原生 1K 上取得该结果。项目已评测静态工具 ID 顺序，但仍不执行真实工具，也不报告参数、返回值或执行成功率。

STAGE METRICSAccuracy → AllHit@K → SetEM / TraceEM

三个阶段分别评测请求分流、候选完整覆盖和精确有序轨迹；它们使用不同测试集，不能合并成一个“端到端成功率”。

SECTION 01

项目背景与三阶段目标

真实电商请求常把订单、物流、优惠与售后组合在同一句话中。本项目沿“先分流、再找齐、后排序”的路径推进：从识别电商请求，到覆盖全部必要工具，再生成符合业务依赖的静态有序工具链。
